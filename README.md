# Hi, I'm Calvin 👋

**Junior Frontend Developer** based in Hagen, Germany

## About me

I started with a three-year apprenticeship as a media designer at an agency in Düsseldorf, with a focus on frontend. There I built websites for clients such as Holtzbrinck, Zwiesel Fortessa Group, Lebensbaum and Aengevelt. Afterwards I worked as a Junior Frontend Developer at active value GmbH, where I led the technical frontend side of a new CMS website. Since 2025 I've been completing a full-stack developer program at the Developer Akademie (Angular, Django). My roots are in frontend and design, and I enjoy building clean, accessible interfaces, but I've come to like the backend side just as much.
